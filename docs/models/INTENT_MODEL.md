# Intent classifier (intent_v1)

Offline evaluation on the **team-generated** intent dataset (`datasets/intents/`, see its README for provenance and limitations). Generated by `pipelines/models/intents.py`.

## Setup
- 504 utterances in 84 paraphrase groups. Held-out test = 4 groups per intent: **144 test / 360 train rows, no group in both** (asserted in code).
- Model family and `C` are selected by 5-fold **grouped** cross-validation on train. The test set is used once.
- Fallback confidence threshold: the lowest threshold whose out-of-fold precision ≥ 95% (on train). Below it, the case escalates instead of being routed.
- Not yet included: zero-shot LLM triage on this same test split (step 3).

## Label validation (blind human review)
A reviewer labeled a stratified random sample of 60 utterances without seeing our labels. **Agreement: 86.7%, Cohen's kappa: 0.84.**

| Id | Text | Our label | Reviewer |
|---|---|---|---|
| p11-1 | el banco me puede pedir el codigo de seguridad por llamada? | card_policy | out_of_scope |
| p13-1 | como se calcula el pago minimo de la tarjeta | card_policy | out_of_scope |
| o03-2 | ¿Qué necesito para abrir una cuenta? | out_of_scope | card_policy |
| p03-3 | ¿cuánto demora en llegar la tarjeta nueva? | card_policy | out_of_scope |
| p11-5 | o banco pede a senha do cartão por WhatsApp? | card_policy | out_of_scope |
| o09-3 | quiero actualizar mi domicilio | out_of_scope | card_policy |
| p09-4 | Quais os requisitos para aumentar o limite do cartão? | card_policy | out_of_scope |
| p03-5 | em quantos dias entregam o cartão de reposição? | card_policy | out_of_scope |

Every disagreement falls on the `card_policy` / `out_of_scope` boundary. The labeling guideline didn't define it explicitly. Our rule, now written into the dataset README, is: a question about how *cards* work (fees, delivery, limits, security practices around cards) is `card_policy`; banking questions about other products or account administration are `out_of_scope`. Labels were kept, not silently changed to match the reviewer, and the ambiguity is reported. In the running system this boundary is low-risk: both routes are read-only (policy RAG with abstention, or a safe refusal).

## Caveats
- Test size is small (one row per utterance, 24 paraphrase groups), so differences of a few points between models aren't significant.
- The data was written by the system's designers, so real customer traffic will be harder. Treat these numbers as an upper bound until validated on real utterances.
