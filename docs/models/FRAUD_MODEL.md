# Suspicious-transaction model (fraud_v1)

Offline evaluation on the synthetic LATAM Bank dataset. Generated by `pipelines/models/fraud.py`.

## Setup
- **Label:** `transactions.is_fraud` on card transactions (real dataset label).
- **Excluded for leakage:**
  - `fraud_score`: it is almost a copy of the label (mean 15 vs. 49 by class).
  - `transaction_status` and `response_code`: they are decided after the fraud check.
- **Features:** amount, channel, type, category, merchant category, card kind, hour, weekday, and whether the country is foreign. Behavioral features use only the card's past: transactions in the last 24h, amount z-score against the card's history, time and km since the previous transaction, implied travel speed, a new merchant, and a country change.
- **Temporal split:** train < 2025-07-01 ≤ valid < 2026-01-01 ≤ test.

| Split | Rows | Positives |
|---|---:|---:|
| train | 1,047,988 | 1,096 |
| valid | 259,861 | 237 |
| test | 239,583 | 215 |

**Model selection** used the validation set only; the selected model is **gradient_boosting**. The test set is reported once and was never used to choose.

## Validation
| Model | PR-AUC (95% CI) | ROC-AUC | Recall @ 1% alerts |
|---|---|---:|---:|
| random (prevalence) | 0.0010 (0.0008–0.0013) | 0.503 | 1.3% |
| rules baseline | 0.0009 (0.0008–0.0012) | 0.498 | 1.7% |
| control: fraud_score (excluded, leaky) | 0.5331 (0.4706–0.5958) | 0.706 | 53.6% |
| logistic_regression | 0.0009 (0.0008–0.0011) | 0.495 | 0.0% |
| gradient_boosting | 0.0009 (0.0008–0.0011) | 0.511 | 0.0% |

## Test (reported once)
| Model | PR-AUC (95% CI) | ROC-AUC | Recall @ 1% alerts |
|---|---|---:|---:|
| random (prevalence) | 0.0008 (0.0007–0.0010) | 0.477 | 0.0% |
| rules baseline | 0.0009 (0.0007–0.0011) | 0.461 | 1.4% |
| control: fraud_score (excluded, leaky) | 0.5643 (0.4973–0.6304) | 0.699 | 56.7% |
| logistic_regression | 0.0009 (0.0008–0.0011) | 0.514 | 0.5% |
| gradient_boosting | 0.0010 (0.0008–0.0012) | 0.515 | 1.4% |

A random ranking has an expected PR-AUC equal to the prevalence (0.0009).

## Conclusion and deployment decision
**Deployment gate:** ship only if the lower bound of the test PR-AUC 95% CI is above the prevalence, i.e. the model beats random with confidence.

**Decision: DO NOT DEPLOY.** No legitimate feature carries signal. Every candidate, including the rules baseline, is indistinguishable from random ranking, while the excluded `fraud_score` alone recovers the label. In this synthetic dataset `is_fraud` appears to be generated independently of the transaction attributes and tied only to `fraud_score`. The assistant therefore does **not** show a model-based fraud flag. Unrecognized charges are handled by the customer's own report plus escalation, which is the safer behavior when there is no validated signal. This is a negative result, reported as such.
