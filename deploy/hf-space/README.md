# Lía API (Factored AI & Data Hackathon 2026)

Backend of **Lía**, the card-support assistant of **Banco Cordillera**, a **fictional** bank.
Customers and transactions come from the hackathon's **synthetic** LATAM Bank dataset; the
policy corpus is **synthetic**. Source code, design, and evaluation:
https://github.com/CarlosOrtiz-21/factored-hackathon-2026-cordillera

This Space only serves the API (`/api/health`, `/api/chat/stream`, ...). The chat and the
auditor panel are the static frontend linked from the repository.
