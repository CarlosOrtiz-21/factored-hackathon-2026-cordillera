# Segurança do cartão

> POLÍTICA SINTÉTICA do Banco Cordillera, um banco fictício (Factored Hackathon 2026). Não corresponde a nenhum banco real.

## 1. Dados que o Banco Cordillera nunca pede
O Banco Cordillera nunca pede a senha, o código de segurança (CVV), a senha do aplicativo nem códigos de verificação por telefone, e-mail, SMS ou WhatsApp. Qualquer pedido desses dados deve ser tratado como tentativa de fraude.

## 2. O que fazer diante de uma tentativa de fraude
Se o cliente passou seus dados para terceiros, deve bloquear o cartão imediatamente e trocar a senha do aplicativo.
