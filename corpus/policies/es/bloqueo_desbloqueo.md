# Bloqueo y desbloqueo de tarjetas

> POLÍTICA SINTÉTICA de Banco Cordillera, un banco ficticio (Factored Hackathon 2026). No corresponde a ningún banco real.

## 1. Tipos de bloqueo
Un bloqueo temporal se usa cuando el cliente no encuentra su tarjeta o quiere pausarla. Un bloqueo definitivo se aplica ante robo, clonación o fraude confirmado.

## 2. Desbloqueo
Una tarjeta con bloqueo temporal puede desbloquearse con un asesor, después de verificar la identidad del cliente. Una tarjeta con bloqueo definitivo no se desbloquea: se repone.

## 3. Bloqueos desde el asistente virtual
El asistente virtual puede solicitar el bloqueo de una tarjeta del cliente autenticado. Por control interno, cada bloqueo es aprobado por un supervisor antes de ejecutarse y queda registrado. El asistente virtual no desbloquea tarjetas.
